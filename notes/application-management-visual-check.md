# Application Management Visual Check

การตรวจ preview บน desktop ยืนยันว่าเมนู Manage เปิดดัชนีสำหรับผู้เล่นซึ่งมี Profile, Plan & usage, Billing & invoices, Application settings, Guides & support และ Privacy & terms เท่านั้น โดยไม่มีรายการผู้ดูแลปรากฏ

เมื่อเลือก Profile แผงดัชนีปิดและแอปแสดงหน้าแยกใน player shell พร้อม breadcrumb กลับสู่ Application Management, สถานะ Preparing และข้อความชัดเจนว่าไม่มีการเรียก API, แก้ข้อมูลแคมเปญ, ขอ login หรือส่ง payment จากหน้านี้
