# อาชีพเริ่มต้น 10 แบบ — Dust & Fire

เอกสารนี้อธิบาย template อาชีพที่หน้า **New Campaign** ใช้จริงใน `client/src/lib/game.ts` โดยออกแบบให้ตัวละครอยู่ในช่วงวัย 18–20 ปี มีความได้เปรียบพอให้เริ่มเรื่องได้ แต่ยังไม่มีอำนาจ สถานะ หรือความชำนาญมากจนกลบการตัดสินใจของผู้เล่น ทุก template มี Mastery 3 รายการซึ่งเริ่มในช่วงโบนัส `+1` ถึง `+3`, สัมภาระที่มีผลใน fiction, สถานะสังคมที่ใกล้กัน และภารกิจเปิดเรื่องที่ทำให้แคมเปญเริ่มเคลื่อนทันที

## หลักออกแบบร่วมกัน

| หลัก | กติกาที่ใช้จริง |

| อายุ | ทุกอาชีพเริ่มอายุ **18–20 ปี** และ progression ใช้อายุนั้นเป็นจุดตั้งต้น |
| Stat | อาชีพกำหนดฐานของ พลังกาย / ฝีมือ / ไหวพริบ / ปัญญา / ใจสู้; ผู้เล่นไม่แจกตัวเลขเอง |

## ภูมิหลังตัวละครและ Stat

อาชีพเป็นฐานของ Stat ทั้งห้าค่า และผู้เล่นไม่แจกตัวเลขเอง. หน้า **Character** มีคำถามภูมิหลังเพียงสองข้อ: **“ก่อนหน้านี้เจ้ามีชีวิตอย่างไร”** และ **“เจ้ายืนหยัดเพื่ออะไร หรือไม่ยืนหยัดเพื่ออะไรเลย”**. คำตอบถูกบันทึกไว้กับ Local Save และส่งให้ AI GM เป็นบริบทเชิงเรื่องเท่านั้น จึงอาจกลับมาเกี่ยวข้องทางอ้อมเป็นข่าวลือ บุคคล สถานที่ แรงกดดัน หรือทางเลือกยาก ๆ เมื่อฉากพาไปถึง แต่ไม่รับประกันว่าจะเกิด และไม่เปลี่ยน Stat, Mastery, DN หรือผลทอย.

หน้า **Confirmation** แสดง “คุณคือใคร”, Stat ทั้งห้า, ภารกิจแรก, Mastery ทั้งหมด, สัมภาระ และภูมิหลังที่ตอบไว้ก่อนเริ่ม Local Save. หน้า Mission และทะเบียนอาชีพใช้คำว่า **ภารกิจแรก** เพื่อให้ชัดเจนว่าเป็นจุดเริ่มเรื่อง ไม่ใช่ภารกิจถาวรของตัวละคร.

## ข้อควรระวังด้านประวัติศาสตร์

คำว่า “ชิโนบิ” ในเกมหมายถึงงานสืบข่าว การสังเกต การแทรกผ่าน และการเอาตัวรอด ไม่ใช่พลังลอบสังหารเหนือจริง. พระนักรบมีบทบาทคุ้มกันและงานเครือข่ายของศาสนสถาน แต่ไม่ได้ทำให้ทุกวัดเป็นฝ่ายทหารเดียวกัน. คนเรือซาไกเป็นแรงงานท่าและลูกเรือ ไม่ใช่พ่อค้านายหน้าที่เริ่มต้นด้วยทุนสูง. นักรบม้าเป็นนายกองหนุ่มที่นำกำลังขนาดเล็กได้ แต่ยังต้องรับคำสั่งและพิสูจน์ตน.
