# Progression UI Visual Review — 2026-08-20

## ตรวจหน้าภารกิจ

หน้า **Mission Dossier** แสดงเจตนาปัจจุบันของเรื่องเป็นข้อมูลอ่านอย่างเดียว โดยไม่มีปุ่มรับงานหรือปุ่มจบงาน ผู้เล่นเห็นผู้ขอ แรงกดดัน เส้นตาย รางวัลเมื่อเรื่องคลี่คลาย ความเสี่ยง และ `Story movement 0/2` ในมุมเดียว การทำงานนี้ตรงกับหลักที่ว่าผลทอยในฉากต้องเป็นตัวขยับภารกิจ

## ตรวจสมุดสัญญา

แท็บเดิมชื่อ Exchange History ถูกเปลี่ยนเป็น **Agreements & Consequences / สมุดสัญญาและผลประโยชน์** แล้ว เนื้อหาบอกผู้เกี่ยวข้อง สิ่งที่เปลี่ยนมือ ผู้จดจำ และผลที่ตามมา จึงไม่สื่อว่าเป็นเพียงประวัติใบเสร็จตลาด

## ตรวจ Save/Load

เมนู More และ top bar ใช้ชื่อ **Save Game** และ **Load Game** ไม่มีคำว่า Campaign Safekeeping แล้ว ทั้งสองหน้าย้ำว่าข้อมูลอยู่ใน browser เดียวกัน มี Auto Save และ Local Save slots เป็นรายละเอียดภายในหน้า Save/Load ไม่ใช่ระบบแคมเปญอีกชั้น

## ผลสรุป

ทั้งสี่หน้าที่ตรวจบน desktop 1440 × 960 แสดง heading และ state ได้ถูกต้อง ไม่มี runtime error ในภาพตรวจ และลำดับข้อมูลสอดคล้องกับวงจร: ฉากผลักเรื่อง → ภารกิจขยับ → รางวัล/ข้อตกลงถูกบันทึก → ผู้เล่นบันทึกหรือโหลด Local Save
