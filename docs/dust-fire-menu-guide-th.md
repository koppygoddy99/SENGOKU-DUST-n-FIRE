# คู่มือเมนูฉบับละเอียด — Dust & Fire: Sengoku Stories

เอกสารนี้อธิบายว่า **ทุกเมนูใน UI เวอร์ชันปัจจุบันทำอะไรได้จริง**, ผู้เล่นเห็นข้อมูลอะไร, ปุ่มใดเปลี่ยนสถานะแคมเปญ, และส่วนใดยังเป็นข้อมูลสำหรับอ่านหรือเป็นระบบที่กำลังขยายต่อไป โดยใช้ **English เป็นชื่อเมนูหลัก** และอธิบายภาษาไทยประกอบ

> **ขอบเขตของเวอร์ชันนี้:** เกมทำงานแบบ **Local-first** เป็นหลัก ข้อมูลแคมเปญ, บันทึก, ตลาด, และเซฟถูกเก็บในเบราว์เซอร์ของผู้เล่นผ่าน Local Save. AI GM เป็นส่วนเสริม; เมื่อผู้ให้บริการ AI ใช้ไม่ได้ เกมจะเปลี่ยนเป็น **Local Trial / กรอกทดลองในเครื่อง** ซึ่งยังวิเคราะห์ ทอย บันทึกฉาก และเซฟได้โดยไม่หักเครดิต AI.

## 1. แผนผังเมนู

```text

│   │   ├── Carried gear
│   │   ├── This market

│   │   └── Exchange history
│   ├── Character

│   ├── World Archive

│   └── Load Game

```

| กลุ่ม | หน้าที่หลัก | ข้อมูลที่เป็นเจ้าของ |
|---|---|---|
| **Campaigns** | เลือกเรื่องที่ต้องการกลับไปเล่น | รายชื่อแคมเปญใน Local Save |
| **Campaign menu** | ใช้ชีวิตภายในแคมเปญที่เลือก | ฉาก ตัวละคร ภารกิจ ตลาด บันทึก และเซฟ |
| **New Campaign** | สร้างตัวละครและเรื่องใหม่ | ตัวตน อาชีพ จุดเด่น/ด้อย และแรงดึง 6 ข้อ |
| **Settings** | ปรับห้องอ่านของเบราว์เซอร์นี้ | ภาษา โหมดสี ขนาดตัวอักษร สีตรา Reader Mode |

## 2. Global UI — สิ่งที่เห็นได้จากทุกหน้าหลัก

### Top Bar

แถบบนบอกบริบทของแคมเปญที่กำลังเล่น ได้แก่ **ปี, ฤดู, แคว้น/พื้นที่, เครดิต, สถานะ UI Preview / Local Trial และตัวเลือก EN/TH**. ปุ่มโลโก้ **Dust & Fire** พากลับไปยัง Campaign Overview เสมอ ส่วนปุ่มเครดิตพาไปหน้า Settings เพื่อให้ผู้เล่นเห็นว่าค่าเครดิตเป็นทรัพยากรของบัญชีในกรณีใช้ AI GM.

### Sidebar — Ledger Spine

Sidebar คือแกนเดินทางของแคมเปญ ผู้เล่นสามารถพับหรือกางได้ตลอดเวลา และเห็นข้อมูลสั้นที่สำคัญโดยไม่ต้องออกจากหน้าเล่น ได้แก่ ชื่อตัวละคร, อาชีพ, บาดแผล, ค่าสติ, แรงฮึด และ “สิ่งที่โลกจดจำ” ล่าสุด. ชื่อแคมเปญใน Sidebar เป็น **parent menu**: เมื่อกดจะพับ/กางเมนูย่อยของแคมเปญนั้น

| สถานะด้านซ้าย | ความหมายในปัจจุบัน | ผลต่อระบบที่ทำงานจริง |
|---|---|---|
| **Wounds / บาดแผล** | ระดับอาการบาดเจ็บจาก 0–6 | แสดงผลแล้ว; กติกาผลเสียจากบาดแผลยังไม่เชื่อมครบทุกกรณี |
| **Focus / ค่าสติ** | ความพร้อมทางใจจาก 0–6 | แสดงผลแล้ว; วงจรเสื่อม/ฟื้นค่าสติยังไม่สมบูรณ์ |
| **Momentum / แรงฮึด** | ทรัพยากรเชิงจังหวะจาก 0–2 | ใช้ 1 เพื่อรับ +2 หลังทอยได้จริง |
| **World remembers / สิ่งที่โลกจดจำ** | ความทรงจำและผลตามมาล่าสุด | อัปเดตจากผลทอยและธุรกรรมที่รองรับ |

## 3. เมนูหลักนอกแคมเปญ

## Campaigns — เลือกแคมเปญ

หน้า **Campaigns** คือคลังแคมเปญ Local Save ของเบราว์เซอร์นี้ แต่ละรายการแสดงชื่อแคมเปญ, ปี, ฤดู, สถานที่, ชื่อตัวละคร, Leaf ล่าสุด และสถานะภารกิจหลัก เพื่อให้แยกเรื่องที่เล่นค้างไว้ได้

| ผู้เล่นทำอะไรได้ | ผลที่เกิดขึ้นจริง |
|---|---|
| เลือกการ์ดแคมเปญ | คัดลอกสถานะของแคมเปญนั้นกลับมาเป็นแคมเปญที่กำลังเล่น และเปิดหน้า Play |
| เริ่ม New Campaign | ไปยังขั้นสร้างแคมเปญใหม่ |
| เปิด Campaign Log ภายหลังเลือก | Log จะแสดงข้อมูลของแคมเปญที่ถูกเลือก ไม่ปนกับเรื่องอื่น |

> **ข้อจำกัด:** แคมเปญอยู่ใน Local Save ของเบราว์เซอร์นี้ ยังไม่มีระบบซิงก์ข้ามเครื่อง, export/import, หรือการจัดการ conflict ระหว่างอุปกรณ์

## New Campaign — สร้างแคมเปญใหม่

หน้า **New Campaign** เป็น flow หลายขั้นในหน้าเดียวสำหรับตั้งโลกตั้งต้นและตัวละคร โดยออกแบบให้ผู้เล่นเลือกคำตอบเชิงเรื่องมากกว่าจัดแต้มตัวเลขเอง

| ขั้น | ผู้เล่นกำหนด | สิ่งที่ระบบสร้างให้ |
|---|---|---|
| 1. เวลาและสถานที่ | ปี, ฤดู, แคว้น/พื้นที่ | บริบทแคมเปญและตลาดเริ่มต้นตามฤดูกาล |
| 2. ตัวตน | ชื่อ, เพศ/ตัวตน, ที่มา, จุดเด่น, จุดด้อย | ตัวตนที่ใช้ในฉากและ Character Dossier |
| 3. Starting Path | เลือกหนึ่งใน 10 อาชีพเริ่มต้น หรือระบุอาชีพอิสระ | แกนทอย, ความชำนาญ, ของเริ่มต้น และภารกิจเริ่มต้น |
| 4. Relationship Pulls | ตอบคำถามเปิดเรื่อง 6 ข้อ | แรงดึง, บุญคุณ, ฝ่ายที่ผูกพัน และประเด็นที่โลกสามารถหยิบกลับมาใช้ |

เมื่อยืนยัน ระบบจะสร้าง **ฉากเปิด, Mission, ตลาด, Economy, ความทรงจำแรก และ Leaf 1** แล้วเปิดหน้า Play.

## 4. เมนูภายในแคมเปญ

## Play — เล่นฉาก

**Play** คือหน้าเล่นหลักและเป็นหัวใจของเกม ผู้เล่นอ่านฉาก แล้วพิมพ์ว่าต้องการทำอะไรเพียงหนึ่งประโยค ระบบเป็นฝ่ายตีความแกนทอย ความชำนาญ โบนัสบริบท และระดับความยากให้

### สิ่งที่ผู้เล่นเห็น

| ส่วน | หน้าที่ |
|---|---|
| **Game Toolbar** | ชื่อแคมเปญ สถานที่ Leaf ปัจจุบัน ปุ่ม Save, Load และเครดิต |
| **Quick Log** | สรุปผลทอยล่าสุดอย่างย่อหลังเกิดการทอย |
| **Historical Boundary** | ขอบเขตว่าข้อความเกี่ยวข้องกับข้อเท็จจริงทางประวัติศาสตร์ บริบท หรือเรื่องสมมติอย่างไร เมื่อมีข้อมูล |
| **Game Paper** | หัวฉาก บริบทสาธารณะ บทละครเต็ม และคำถามที่ฉากโยนกลับมาหาผู้เล่น |
| **Suggested Actions** | ปุ่มข้อเสนอการกระทำจากฉาก ผู้เล่นกดเพื่อเติมในช่องคำสั่งแล้วแก้เองได้ |
| **Action Dock** | ช่องให้พิมพ์หนึ่งประโยค ปุ่ม Assess Risk, Analyze, และ Confirm & Roll |

### วงจรเล่นจริง

1. **Say what you will do in one sentence / การกระทำของเจ้า** — พิมพ์การกระทำที่ต้องการทำ
2. **Assess Risk / ประเมินความยาก** — ดูแรงกดดันและระดับความยาก แต่ยังไม่เปิดแกนทอยหรือความชำนาญ
3. **Analyze Locally / วิเคราะห์ในเครื่อง** — Local Trial เลือกแกนทอย ความชำนาญ และโบนัสบริบทให้จากข้อความและของที่มี
4. **Confirm & Roll / ยืนยันและทอย** — ทอย 2d12 แบบ deterministic rule engine และเลือกใช้ Momentum ได้หากมี
5. **Record** — ระบบบันทึก Roll, Memory, Scene, Leaf และ Local Save; Campaign Log จะอ่านผลที่เกิดขึ้นได้ทันที

### กติกา Local Trial ที่ใช้งานได้

| กลไก | การทำงานจริง |
|---|---|
| **2d12** | ทอย d12 สองลูก แล้วบวกแกนทอย, ความชำนาญ, โบนัสของ และ Momentum ถ้าใช้ |
| **Axis** | ระบบเลือก Prowess, Craft, Instinct, Judgment หรือ Resolve จากคำสำคัญในประโยคผู้เล่น |
| **Difficulty** | ใช้ระดับ DN 10, 14, 18 หรือ 22 ตามความเสี่ยงของการกระทำ |
| **Outcome** | มี decisive success, success with cost, partial success และ failure with consequence |
| **Momentum** | ใช้ 1 Momentum เพื่อ +2 หลังทอยได้ |
| **เครดิต AI** | Local Trial ไม่หักเครดิต AI แม้ AI GM ใช้งานไม่ได้ |

> **ข้อจำกัด:** parser ใน Local Trial ยังพึ่งคำสำคัญและกติกาเชิง heuristic. บาดแผล, ค่าสติ, เสบียง, ชื่อเสียง และภารกิจยังไม่ได้ส่งผลอัตโนมัติครบทุกกรณี. AI GM เป็นระบบเสริมและปัจจุบันอาจ fallback เป็น Local Trial ตามสถานะผู้ให้บริการ

## Missions — Mission Ledger

หน้า **Missions** แสดงงานที่โลกเรียกร้องจากผู้เล่น ไม่ใช่แค่รายการเควสเพื่อเงินรางวัล แต่บอกฐานะของผู้มอบงาน รางวัลที่เขาจ่ายได้ แรงกดดัน และราคาที่อาจตามมา

| ข้อมูล | ผู้เล่นใช้ตัดสินใจอะไร |
|---|---|
| **Issuer / ผู้มอบงาน** | ใครเรียกร้องงานและอยู่ในชนชั้นหรือเครือข่ายใด |
| **Request / คำขอ** | เป้าหมายของภารกิจ |
| **Pressure / แรงกดดัน** | เหตุใดงานนี้จึงไม่ควรถูกปล่อยไว้ |
| **Deadline / เส้นตาย** | เวลาในเรื่องที่ควรเร่งตัดสินใจ |
| **Reward / รางวัล** | รางวัลตามสถานะผู้มอบงาน เช่น การคุ้มครอง เส้นทาง ข่าว หรือทรัพยากร ไม่ยึดเงินสดเป็นหลัก |
| **Risk / ความเสี่ยง** | สิ่งที่อาจสูญเสียหากรับหรือทำพลาด |

### ปุ่มที่ทำงานจริง

- **Accept / รับงาน**: เปลี่ยนสถานะงานจาก `offered` เป็น `active` ใน Local Save
- **Continue / ไปต่อ** และตัวเลือกงาน: พากลับไปหน้า Play เพื่อให้ผู้เล่นใช้การกระทำหนึ่งประโยคจัดการสถานการณ์

> **ข้อจำกัด:** ระบบยังอัปเดตความคืบหน้าของภารกิจแรกเป็นหลัก วงจรหลายภารกิจพร้อมกัน, เป้าหมายย่อย, การหมดเวลา, รางวัลจริง และผลตอบสนองจากผู้มอบงานยังอยู่ในแผนขยายต่อไป

## Market & gear — ตลาดและสัมภาระ

**Market & gear** เป็น parent menu ที่รวม 5 บัญชีซึ่งเล่าเศรษฐกิจและสัมภาระของแคมเปญในมุมเดียวกัน: สิ่งที่มีอยู่, สิ่งที่ตลาดเสนอ, คนที่ช่วยได้, สิ่งที่ค้าง และสิ่งที่เกิดขึ้นแล้ว

### Carried gear — ของที่พกอยู่

หน้านี้แสดงสัมภาระของตัวละครและจำนวนช่องที่ใช้จากขีดจำกัด 8 ช่อง

| ข้อมูล | ความหมาย |
|---|---|
| **Carried slots** | จำนวนช่องสัมภาระที่ใช้แล้ว |
| **Item** | ชื่อและคำอธิบายของสิ่งของ |
| **Location** | พกติดตัว, อยู่เซฟเฮาส์, เก็บไว้ หรือซ่อนไว้ |
| **Ownership** | ของตน, ยืมมา, ถือแทนผู้อื่น หรือมีข้อพิพาท |

สิ่งของบางชิ้นมีโบนัส ซึ่ง Local Trial สามารถหยิบมาใช้โดยอัตโนมัติเมื่อแท็กของไอเทมสอดคล้องกับการกระทำที่พิมพ์

> **ข้อจำกัด:** ยังไม่มีปุ่ม “ใช้ของ”, “ซ่อม”, “สวม”, “ย้ายที่เก็บ”, “มอบให้”, หรือ “บริโภค” ที่เปลี่ยน condition ของไอเทมโดยตรง

### This market — ตลาดพื้นที่นี้

หน้านี้แสดงรายการสิ่งที่หาได้ในพื้นที่ปัจจุบัน พร้อมเหตุผลของราคา เพราะตลาดไม่ใช่แคตตาล็อกสากล สินค้าเชื่อมกับฤดู เส้นทาง สงคราม และเครือข่ายผู้ขาย

| สิ่งที่เห็น | การทำงานจริง |
|---|---|
| **Market context / Route status** | อธิบายสถานการณ์พื้นที่และเส้นทางการค้า |
| **Offer** | สินค้า บริการ หรือข่าว พร้อมราคาและเหตุผลของราคา |
| **Take Offer / รับข้อเสนอ** | ซื้อ/รับรายการที่รองรับ แล้วบันทึก transaction และ memory |
| **Availability** | รายการที่รับแล้วจะเปลี่ยนเป็น `recorded` และกดซ้ำไม่ได้ |

กรณีเฉพาะของเซฟไซกะ: ผู้เล่นอาจรับ **ยาสมุนไพร** ด้วยการค้ำประกันได้เมื่อทรัพย์สินไม่พอ ระบบจะเพิ่มร่องรอยหนี้ใน obligation และ exchange history.

> **ข้อจำกัด:** การสุ่มสินค้าใหม่, การต่อรอง, ตลาดตามฤดูกาลแบบเคลื่อนไหว, การเปลี่ยนแปลงจากเวลา และการใช้บริการจากรายการตลาดยังไม่เป็นระบบเต็มรูปแบบ

### Services & hands — บริการและคนรับจ้าง

หน้ารวมคนที่ช่วยได้ในตลาดและข้อมูลที่ผู้เล่นควรรู้ก่อนขอความช่วยเหลือ

| ฟิลด์ | คำตอบที่ผู้เล่นได้รับ |
|---|---|
| **Provider / Role / Network** | ใครช่วยได้ ทำหน้าที่ใด และเกี่ยวข้องกับเครือข่ายใด |
| **Request** | ผู้ให้บริการต้องการให้ผู้เล่นทำหรือส่งอะไร |
| **Price / Time** | ราคาที่จ่ายได้และเวลาที่จะเสีย |
| **Condition** | ข้อห้ามหรือเงื่อนไขก่อนรับงาน |
| **Witness risk** | ใครอาจรู้เรื่องของผู้เล่นจากการว่าจ้าง |

> **ข้อจำกัด:** หน้านี้เป็น ledger สำหรับอ่านและวางแผน ยังไม่มีปุ่มยืนยัน “ว่าจ้าง” ที่ทำให้เวลาผ่าน, ทรัพยากรถูกหัก หรือ NPC ทำงานเสร็จใน Local Save

### Credit, debts & favors — เครดิต / หนี้ / บุญคุณ

หน้านี้แสดงภาระผูกพันในแบบสังคมยุคสงคราม ไม่ใช้ “คะแนนเครดิตชาติเดียว” ผู้เล่นจึงต้องจำว่าใครถือสิทธิ์ทวงอะไร, สิ่งใดเป็นบุญคุณ, และมีพยานคนใดรู้เรื่อง

| ฟิลด์ | ความหมาย |
|---|---|
| **Kind** | `credit`, `debt` หรือ `favor` |
| **Holder** | ผู้ถือสิทธิ์หรือเครือข่ายที่ผู้เล่นติดค้าง |
| **Subject** | สิ่งที่ค้างหรือบุญคุณที่รับไว้ |
| **Due / Witness** | เวลา/เงื่อนไขที่อาจถูกทวง และผู้ที่รับรู้ |
| **Status** | `open`, `settled` หรือ `called_in` |

> **ข้อจำกัด:** ยกเว้นการรับยาด้วยการค้ำประกันที่เชื่อมระบบแล้ว ยังไม่มีปุ่มชำระหนี้, ใช้บุญคุณ, เรียกเครดิต หรือเจรจาเงื่อนไขโดยตรง

### Exchange history — ประวัติการแลกเปลี่ยน

หน้าประวัติให้ผู้เล่นย้อนดูสิ่งที่เกิดขึ้นแล้ว ทั้งการซื้อ, รับของแบบเป็นหนี้, ว่าจ้าง, ให้ของ, ได้บุญคุณ หรือเกิดภาระ

| ข้อมูล | ความหมาย |
|---|---|
| **Kind / Leaf** | ประเภทการแลกเปลี่ยนและช่วงเรื่องที่เกิด |
| **Counterpart** | แลกกับใคร |
| **Payment** | จ่ายด้วยทรัพย์สิน หนี้ ข้อมูล แรงงาน หรือบุญคุณอย่างไร |
| **Witness** | ใครเห็นหรือรู้เรื่อง |
| **Consequence** | ร่องรอยที่การแลกเปลี่ยนทิ้งไว้ในโลก |

หน้านี้อัปเดตเมื่อใช้การซื้อของหรือธุรกรรมที่ระบบรองรับ

## Character — Character Dossier

หน้า **Character** คือแฟ้มตัวละคร ใช้ตรวจข้อมูลกลไกที่ผู้เล่นมีสิทธิ์รู้ ไม่ต้องเดาว่าระบบตีความตัวละครอย่างไร

| แท็บ | สิ่งที่แสดง |
|---|---|
| **Traits / แกนทอย** | Prowess, Craft, Instinct, Judgment, Resolve พร้อมคำใบ้การใช้งาน |
| **Masteries / ความชำนาญ** | โบนัส, ต้นทาง, และความชำนาญที่ action parser หรือ AI GM อาจเลือกใช้ |
| **Gear / สัมภาระ** | รายการของ, ช่องสัมภาระ และคำอธิบาย |
| **Ties / แรงดึง** | คำตอบ 6 ข้อที่ผู้เล่นให้ไว้และแท็กเนื้อเรื่อง |
| **Social Record** | Honor, Influence, Information และ Stain |

ค่าทางสังคมใน Social Record ไม่ใช่คำสั่งให้ NPC เชื่อฟังอัตโนมัติ แต่เป็นภาษากลางสำหรับสิทธิ์เข้าถึง, ความสนใจที่ได้รับ, ข่าวในมือ และราคาของความพลาด

> **ข้อจำกัด:** ไม่มีการแก้ character sheet, พัฒนาความชำนาญ, เปลี่ยนสถานะอุปกรณ์ หรืออัปเลเวลจากหน้านี้โดยตรง

## Campaign Overview — ภาพรวมแคมเปญ

หน้า **Campaign Overview** คือหน้า landing ของเรื่องที่กำลังเล่น และเป็นหน้าที่มีใน Sidebar ใต้ชื่อแคมเปญก่อน Campaign Log

| ส่วน | หน้าที่ |
|---|---|
| **Campaign Record header** | ชื่อแคมเปญและสถานะว่าเป็น local-first campaign |
| **Current Leaf** | ฉากค้างเล่นล่าสุด บทนำ และปุ่มกลับสู่ Play |
| **Margin Note** | เวลา สถานที่ ภาระ และเครดิต |
| **Shortcuts** | ทางลัด Mission Ledger, Character Dossier, Campaign Record และ World Index |

ใช้หน้านี้เมื่ออยากกลับมาดูภาพใหญ่ของเรื่อง ก่อนเลือกว่าจะอ่าน Log, จัดการตัวละคร, หรือกลับไปเล่นฉากต่อ

## Campaign Log — บันทึกเรื่องราว

หน้า **Campaign Log** คือทะเบียนเหตุการณ์ของแคมเปญ โดยรวม World Memories และ Roll Records แล้วเรียงตาม Leaf

### Reader Mode

เมื่อเปิด **Reader Mode** จะซ่อนตัวเลขทอยและเน้นร้อยแก้ว เพื่อให้อ่านเหตุการณ์ที่เกิดขึ้นเป็นเรื่องต่อเนื่อง ผู้เล่นเลื่อนไปมาระหว่าง entry ก่อนหน้าและถัดไปได้

### Normal Log

เมื่อปิด Reader Mode ผู้เล่นค้นหาบันทึกได้ และเห็นชนิด record, Leaf, ข้อความผล, เรื่องราว และตัวเลข 2d12 ของ roll ที่เกี่ยวข้อง

> **ข้อจำกัด:** Log ยังไม่มีแท็กกรองตาม NPC, สถานที่, ภารกิจ หรือประเภทหนี้/บุญคุณ และไม่มี export เป็นไฟล์ภายใน UI

## World Archive — คลังโลก

หน้า **World Archive** รวมสิ่งที่แคมเปญเปิดเผยแล้วเท่านั้น เพื่อไม่ให้ผู้เล่นได้รู้ข้อมูลลับที่ตัวละครยังไม่พบ

| ส่วน | สิ่งที่สรุป |
|---|---|
| **Current place / War shadow** | สถานที่ตอนนี้ แรงกดดัน และระดับเงาสงคราม |
| **People who matter** | คนที่ฉากและภารกิจปัจจุบันชี้ว่าเกี่ยวข้อง |
| **Mission pressure** | แรงกดดันของภารกิจหลัก |
| **World memories** | จำนวนข้อมูลที่โลกบันทึกไว้ |
| **Community condition** | Food และ Safety ของชุมชน |
| **Recent memories** | เหตุการณ์ล่าสุดที่แคมเปญจดจำ |

> **ข้อจำกัด:** ยังไม่มีแผนที่สถานที่, roster NPC แบบละเอียด, ไทม์ไลน์ประวัติศาสตร์เชิงโต้ตอบ, หรือหน้าอ่าน fact cards. หน้าแผนที่สถานที่เป็นหนึ่งใน UI ที่กำลังจะออกแบบต่อจากการทบทวนหน้า Play

## Save Game — บันทึกเกม

หน้า **Save Game** เป็นที่จัดการ Leaf ใน Local Save

| ช่อง | การทำงาน |
|---|---|
| **Auto Save** | อัปเดตตามสถานะแคมเปญปัจจุบันทุกครั้งที่มีการเปลี่ยนแปลงสำคัญ |
| **Manual Save** | ผู้เล่นกดบันทึกหรือเขียนทับเอง |
| **Saved Leaf II** | จุดบันทึกท้องถิ่นเพิ่มเติม |
| **Saved Leaf III** | จุดบันทึกท้องถิ่นเพิ่มเติม |

ปุ่ม **Save Here / Overwrite** เขียน snapshot ของ `GameState` ปัจจุบันลงช่องนั้น และยังไม่ลบ Auto Save.

## Load Game — โหลดเกม

หน้า **Load Game** แสดง Auto Save และ Leaf ที่ผู้เล่นเก็บด้วยมือ พร้อมชื่อแคมเปญ, Leaf, ตัวละคร, และหัวฉากล่าสุด

เมื่อกด **Load** ระบบคัดลอกสถานะจาก slot ที่เลือกกลับมาเป็นแคมเปญปัจจุบัน แล้วเปิดหน้า Play. จุดเซฟต้นทางยังอยู่ จึงโหลดกลับซ้ำได้

> **ข้อจำกัด:** เซฟทั้งหมดเป็นแบบ local browser; การเคลียร์ข้อมูลเบราว์เซอร์อาจลบเซฟ จึงควรมี export/import หรือ cloud save ก่อนใช้เล่นระยะยาว

## Settings — ตั้งค่า

หน้า **Settings** เปลี่ยนเฉพาะสภาพการอ่านและพฤติกรรม Local Save ของเบราว์เซอร์นี้ ไม่เปลี่ยนกติกาเกมหรือสถานะแคมเปญโดยตรง

| การตั้งค่า | ผลลัพธ์ |
|---|---|
| **Appearance** | เปิด/ปิดโหมดมืด |
| **Text size** | เลือก small, normal หรือ large |
| **Seal accent** | เปลี่ยนสีเน้น vermilion, ochre หรือ teal |
| **Reader Mode** | ตั้งค่าเริ่มต้นของการเปิด Campaign Log เป็นโหมดอ่านเรื่อง |
| **Language** | สลับ EN/TH โดย English เป็นภาษาหลัก |
| **Clear Local Save** | ลบ Local Save แล้วเริ่มจากตัวอย่างเซฟไซกะใหม่ |

> **ข้อควรระวัง:** Clear Local Save ล้างแคมเปญและ Leaf ในเบราว์เซอร์นี้ ดังนั้นควรมีระบบ export ก่อนใช้ฟังก์ชันนี้กับแคมเปญที่เล่นจริง

## 5. สถานะระบบตามระดับความพร้อม

| ระดับ | ระบบ |
|---|---|
| **เล่นได้จริงใน Local Trial** | สร้าง/เลือกแคมเปญ, หน้า Play, 2d12, Momentum, scene continuation, Log, Reader Mode, Local Save/Load, การรับข้อเสนอที่รองรับ, transaction history |
| **ใช้ดูและวางแผนได้** | Missions, Services & hands, Credit/debts/favors, Character Dossier, World Archive |
| **มีข้อมูล แต่ต้องขยาย action loop** | ใช้ของ, ว่าจ้างบริการ, ชำระหนี้, เรียกบุญคุณ, สถานะบาดแผล/ค่าสติ/เสบียง, progression, mission chain |
| **ยังไม่ใช่ Local-first core** | เซฟข้ามอุปกรณ์, export/import, ระบบแผนที่, ไทม์ไลน์เชิงโต้ตอบ, NPC roster เชิงลึก |

## 6. วิธีใช้เอกสารนี้เพื่อปรับ UI ทีละหน้า

1. เลือกชื่อหน้าในเอกสารหรือสไลด์ เช่น **Play**, **Market**, หรือ **Campaign Log**
2. ระบุส่วนที่อยากเปลี่ยน เช่น “ทำบทละครกว้างขึ้น”, “ย้าย quick log ไปไว้ด้านขวา”, “ปุ่มทอยเด่นขึ้น”, หรือ “ให้หนี้อ่านง่ายกว่าเดิม”
3. ระบุความสำคัญ: ต้องแก้ก่อน, แก้ถัดไป, หรือเก็บไว้หลังทำหน้าแผนที่
4. ระบบจะปรับเฉพาะหน้านั้น, แคปภาพใหม่ให้ตรวจ และไม่เปลี่ยนกติกาหลังบ้านโดยไม่บอกก่อน

> **จุดเริ่มที่แนะนำ:** เริ่มจาก **Play** เพราะเป็นหน้าที่ใช้เวลามากที่สุดในการเล่นจริง จากนั้นตามด้วย **World Archive → Map UI**, **Missions**, และ **Market & gear**.
