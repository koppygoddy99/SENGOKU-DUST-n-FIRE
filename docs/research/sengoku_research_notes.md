# บันทึกข้อค้นพบจากแหล่งข้อมูลเว็บ

## National Diet Library: NINJA in Fiction and in Reality
แหล่งข้อมูล: https://www.ndl.go.jp/kaleido/e/entry/33/2.html

ประเด็นที่ใช้ได้: คำว่า shinobi มีประวัติการใช้หลายแบบ และคำเรียกในยุคสงครามไม่ได้เท่ากับภาพ “นินจา” แบบสื่อสมัยใหม่เสมอไป NDL อ้างตัวอย่างจากบันทึกและเอกสารที่กล่าวถึงภารกิจลอบแทรกซึม ข่าวกรอง การจู่โจมยามค่ำ และการลาดตระเวน นอกจากนี้อธิบายว่า Iga และ Kōka/Kōga มีชุมชนที่ปกครองตนเองและบางครั้งต่อต้านการรุกรานด้วยการซุ่มโจมตีและการจู่โจมก่อน ไม่ควรนำรายละเอียดงานสายลับยุค Edo เช่น Oniwaban ย้อนกลับไปใช้เป็นสถาบันของยุค Sengoku โดยตรง

ระดับความแน่นอน: มีหลักฐานสนับสนุนสำหรับการมีอยู่ของภารกิจ shinobi และชุมชน Iga/Kōka; รูปแบบการแต่งกาย อาวุธลับ และขอบเขตการเป็น “อาชีพ” เป็นประเด็นที่ต้องระบุว่าเป็นข้อถกเถียงหรือแต่งเติมเพื่อเกม

## Britannica: Samurai, Farming, Villages
แหล่งข้อมูล: https://www.britannica.com/place/Japan/Samurai-groups-and-farming-villages

ประเด็นที่ใช้ได้: warrior-landlords อาศัยในหมู่บ้านเกษตรและกำกับแรงงานชาวนา/ทำเกษตรเอง; ขุนนาง วัด และศาลเจ้าถือพื้นที่สาธารณะและ shōen; ผู้ถือสิทธิท้องถิ่นสามารถเป็นทั้งนักรบ เจ้าหน้าที่จังหวัด และตัวแทนของ shōen; การพัฒนานาข้าวและชลประทานเป็นงานเชิงอำนาจ ไม่ใช่ฉากพื้นหลังเฉย ๆ วัดและศาสนสถานมีทรัพยากรและอิทธิพลทางสังคมที่เชื่อมกับนักรบและชุมชน

ระดับความแน่นอน: มีหลักฐานสนับสนุนในระดับภาพรวมของโครงสร้างหมู่บ้านและอาณาเขต แต่ไม่ควรใช้เป็นคำอธิบายแบบเดียวกับทุกแคว้นใน ค.ศ. 1467–1615

## ใช้กับงานต่อไป
ข้อสรุปหลักคือฐานข้อมูล NPC ต้องเก็บ “ตำแหน่ง/เครือข่าย/ผู้ให้สิทธิ/ทรัพยากร/สิ่งที่รู้” แยกจากชนชั้นแบบป้ายเดียว และต้องรักษาความต่างระหว่าง shinobi, jizamurai, ashigaru, rōnin และเจ้าหน้าที่หมู่บ้าน การวิจัยรายละเอียดเพิ่มเติมควรใช้บันทึกหมู่บ้าน บัญชีภาษี จดหมาย สัญญา และงานวิชาการเฉพาะภูมิภาค

## แหล่งภาษาญี่ปุ่นที่เปิดอ่านแล้ว

### 国立国会図書館: 本の万華鏡 第33回「NINJA 虚像と実像」
URL: https://www.ndl.go.jp/kaleido/entry/33/2.html

ข้อความภาษาญี่ปุ่นระบุว่าแหล่งเก่าสุดที่อธิบายกิจกรรมของ忍者อย่างเป็นรูปธรรมในญี่ปุ่นคือ『太平記』ราวยุค Ōan (1368–1375) และบันทึกยุคสงครามใช้คำเรียกหลายแบบ เช่น 「くさ」「かまり」「透波」「乱波」ขณะที่คำว่า 「忍者」เป็นคำเรียกสมัยใหม่กว่ามาก NDL อธิบายภารกิจที่ต้องซ่อนตัว ลอบเข้า ทำงานเสี่ยง และกรณี Iga/Kōka สร้างชุมชนที่มี自治และต่อต้านผู้รุกรานด้วยการซุ่มโจมตี/จู่โจมกลางคืน ระดับความแน่นอน: มีหลักฐานสนับสนุนสำหรับภารกิจและคำเรียกหลายแบบ แต่ภาพเครื่องแต่งกาย/อาวุธลับแบบป๊อปคัลเจอร์ไม่ควรถือเป็นหลักฐานตรง

### 京都橘大学: 「土豪を探す」โดย 野田泰三
URL: https://www.tachibana-u.ac.jp/admission/tcbn/contents/1-3noda.html

บทความอธิบาย 「土豪・地侍」ว่าเป็นนักรบหน้าใหม่ที่มีฐานเดิมจากเกษตรกรผู้มีอำนาจในหมู่บ้าน/荘園 ต่อมาได้สถานะ侍ตั้งแต่ครึ่งหลังคริสต์ศตวรรษที่ 15 มีส่วนบริหารหมู่บ้าน บางคนเป็นผู้ใต้บังคับบัญชาของไดเมียว/家臣 ออกรบ และทำหน้าที่ปกครองท้องถิ่น ตัวอย่างเอกสารราว ค.ศ. 1550 แสดงนักรบเจ็ดคนจากหมู่บ้านรอบ Kyoto ที่อยู่ใต้ Miyoshi Nagayoshi และร่วมออกคำสั่งงานก่อสร้าง Katsuryūji-jō บทความยังยกกรณีตระกูล Nakaji ซึ่งบางสายทำงานกับ Matsunaga/ผู้ครองหลายสมัย และภายหลังบางสายเป็นซามูไรต่อ ขณะที่บางสายกลับเป็น庄屋/ผู้ใหญ่บ้าน แสดงว่าตำแหน่งและเส้นทางชีวิตเปลี่ยนได้ ไม่ควรใช้ “ชาวนา” กับ “ซามูไร” เป็นกล่องตายตัว

ระดับความแน่นอน: มีหลักฐานสนับสนุนสูงสำหรับกรณีศึกษาที่บทความอ้างถึง; การขยายรูปแบบไปทั่ว 66 แคว้นต้องติดป้ายเป็นการสังเคราะห์/ข้ออนุมาน

## Fukui Prefectural History: ภาษีและข้อจำกัดของหลักฐาน

แหล่งข้อมูล: https://www.library-archives.pref.fukui.lg.jp/fukui/07/kenshi/T2/T2-4-01-03-04-02.htm

ประวัติศาสตร์จังหวัด Fukui ระบุอย่างชัดเจนว่าเอกสารที่อธิบายรายละเอียดการเก็บ年貢・公事จากชาวนาโดย Takeda หรือผู้ใต้บังคับบัญชาในระดับ所領สำหรับยุคสงครามมีน้อยมาก ตัวอย่าง ค.ศ. 1551/天文20 แสดงการเก็บข้าวภาษี 地子銭 段銭 และ公事 โดยผู้ปกครองท้องถิ่น/城主ทำหน้าที่เป็นตัวกลางโดยตรง ส่วนกรณี浦 มีการส่ง海産物เป็นภาษีด้วย ข้อมูลนี้สนับสนุนการออกแบบเศรษฐกิจแบบหลายชั้น: ผู้เก็บสิทธิเดิม–ผู้รับมอบอำนาจ–ผู้ปกครองทหาร–หมู่บ้าน ไม่ใช่ภาษีที่ส่งตรงจากชาวนาไปยังไดเมียวเสมอ

ระดับความแน่นอน: มีหลักฐานสนับสนุนสูงสำหรับตัวอย่าง Echizen และข้อจำกัดของหลักฐาน; ไม่ควรเหมารวมตัวเลข/รายการภาษีนี้กับทุกแคว้น

## แหล่งเทคนิคสำหรับ world state และ AI context

### JSON Schema Draft 2020-12
URL: https://json-schema.org/draft/2020-12

มาตรฐานทางการเผยแพร่ 16 มิถุนายน 2022 และมี metaschema ที่ `https://json-schema.org/draft/2020-12/schema` รุ่นนี้ปรับ array/tuple เป็น `prefixItems` และ `items`, เพิ่ม `$dynamicRef`/`$dynamicAnchor`, แยก vocabularies และมีแนวทาง bundling schema ใช้เป็นฐานของ schema เกมได้ แต่ต้องกำหนด enum/format/provenance ของ Sengoku เอง

### PostgreSQL JSON Types
URL: https://www.postgresql.org/docs/current/datatype-json.html

เอกสารทางการระบุว่า `jsonb` เก็บเป็นรูปแบบแยกโครงสร้าง ทำให้ประมวลผลเร็วกว่า `json` ที่ต้อง parse ใหม่ และรองรับ indexes เช่น GIN แต่ไม่รักษาลำดับ key/whitespace และ duplicate keys ดังนั้นข้อเสนอคือใช้ jsonb สำหรับรายละเอียด flexible และสร้าง relational/materialized projections หรือ expression indexes สำหรับ query ร้อน เช่น heat, faction, region, date, salience ไม่ควร scan world JSON ก้อนเดียวทุกฉาก

URL: https://www.anthropic.com/engineering/contextual-retrieval

บทความเผยแพร่ 19 กันยายน 2024 อธิบาย RAG, semantic embeddings, BM25, rank fusion, reranking และการเติมบริบทเฉพาะ chunk ก่อนทำ index (Contextual Embeddings/Contextual BM25) โดยรายงานว่าลด failed retrieval ได้ 49% และเมื่อรวม reranking 67% ในการทดลองของบทความ ควรนำหลักการมาใช้กับเอกสาร faction/event/NPC memory โดยเติม region/time/faction/event context ก่อน indexing แยก canonical facts จาก beliefs/rumors และใช้ top-k ที่ rerank ไม่ส่ง world state ทั้งหมดให้ AI

## Japan Heritage (文化庁): 忍びの里 伊賀・甲賀

URL: https://japan-heritage.bunka.go.jp/ja/stories/story042/

แหล่งของ文化庁อธิบาย Iga/Kōka ว่าเป็นพื้นที่ภูมิประเทศเนินเขาและหุบเขาซับซ้อน มี城館土塁จำนวนมาก การสื่อสารระหว่างชุมชน และ地侍ที่รวมตัวเป็น「伊賀惣国一揆」กับ「甲賀郡中惣」มีการปรึกษาหารือ/「一味同心」และใช้การรวมกลุ่มป้องกันพื้นที่ เว็บไซต์ยังกล่าวถึงบทบาทของพวกเขาในฐานะคนทำเกษตรยามสงบและผู้เชี่ยวชาญการสอดแนม/รบเมื่อเกิดสงคราม รวมถึงความรู้ด้านไม้ ยาสมุนไพร ศาสนาภูเขา และไฟ/สารเคมีในวัฒนธรรมท้องถิ่น

ข้อควรระวังเชิงประวัติศาสตร์: หน้า Japan Heritage จัดทำเพื่อสื่อสารมรดกท้องถิ่นและอาจเล่าเส้นเรื่องแบบรวมภาพ ควรใช้เป็นหลักฐานสนับสนุนด้านสถานที่/ความทรงจำและโครงสร้างชุมชน ไม่ใช้ยืนยันว่าทุกคนใน Iga/Kōka เป็น “นินจาอาชีพ” หรือว่ารายละเอียดจาก『伊乱記』/『萬川集海』สะท้อนทุกปีของ Sengoku โดยตรง
