# สไลด์: ค่า DN และกติกาหลักของ Dust & Fire

เอกสารนี้เป็นสารบัญและฐานเนื้อหาของสไลด์ **Dust & Fire — DN & Core Rules** ซึ่งจัดทำจาก implementation ที่ตรวจรับแล้ว ณ รอบกติกา DN ล่าสุด สไลด์ฉบับนำเสนอมี 12 หน้า และครอบคลุม DN, สูตร 2d12, Margin, Momentum, ตัวอย่างคำนวณ, Narrative Outcome และวงจร XP/เวลา/ภารกิจ

| ลำดับ | หัวข้อ | ข้อสรุปหลัก |
|---:|---|---|
| 1 | หน้าปก | Ledger of Ash player briefing สำหรับกติกาปัจจุบัน |
| 2 | เกมเริ่มจากหนึ่งประโยค | ผู้เล่นบอกวิธีและเป้าหมาย; ระบบรับผิดชอบการเลือกกติกา |
| 3 | สูตรผลทอย | `2d12 + Axis + Mastery + Context + Momentum` เทียบ DN |
| 4 | DN คือแรงกดดัน | DN วัดเดิมพัน/อุปสรรค ไม่ใช่โทษหรือคะแนนคุณค่าผู้เล่น |
| 5 | สามระดับ DN | DN14 เดิมพันปกติ, DN18 อุปสรรคจริง, DN22 วิกฤตซ้อน |
| 6 | เหตุผลเชิงสมดุล | ใช้ exhaustive enumeration ของผล 2d12 ทั้ง 144 คู่เพื่อยืนยัน guardrails |
| 7 | Margin outcomes | ทุกผลทำให้เรื่องขยับ และไม่มี dead end |
| 8 | Momentum | เพิ่ม Total +2 หลังเห็นผล แต่ไม่ลบพยาน บาดแผล หรือราคา |
| 9 | ตัวอย่างคำนวณ | `7 + 4 + 3 + 2 + 1 = 17` เทียบ DN14 ได้ Margin +3 |
| 10 | Narrative Outcome | Draft ร้อยเรียงข้อความก่อนเปิดผลเต็มและ composer ตาถัดไป |
| 11 | วงจรความก้าวหน้า | ผลทอยขยับ XP เวลา ภารกิจ รางวัล Memory และ Local Save |
| 12 | สรุปก่อนทอย | ผู้เล่นจำเพียงเจตนา สูตร DN Momentum และการเล่นต่อ |

## ตัวเลขที่อ้างอิงในสไลด์

Distribution บนสไลด์สมดุลคำนวณจาก `scripts/analyze-dn-balance.mjs` โดย enumerate ผลลูกเต๋า `2d12` ครบ 144 คู่ ไม่ใช้การสุ่มจำลอง ตารางด้านล่างแสดงสัดส่วน outcome ตามโบนัสและ DN ที่เลือกเป็นตัวอย่าง

| โบนัส / DN | สำเร็จ | ได้บางส่วน | พลาดพร้อมผล |
|---|---:|---:|---:|
| +3 / DN10 | 89.6% | 9.7% | 0.7% |
| +3 / DN14 | 68.8% | 20.8% | 10.4% |
| +5 / DN18 | 54.2% | 26.4% | 19.4% |
| +3 / DN22 | 13.9% | 23.6% | 61.8% |
