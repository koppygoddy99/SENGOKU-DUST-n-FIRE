## ข้อค้นพบที่ใช้กับแคมเปญซะไก/อิซุมิ

แหล่งข้อมูลท้องถิ่นของเมืองซะไกระบุว่าเมืองอยู่ใกล้ทะเลและเกี่ยวข้องกับรอยต่อของแคว้น Settsu กับ Izumi; ยังอธิบายการเติบโตของซะไกในฐานะท่าเรือและศูนย์กลางการค้าทางทะเลในยุคกลาง/เซ็นโกกุ ข้อมูลนี้รองรับเฉพาะภาษา UI ว่าแคมเปญซะไกอยู่ในบริบท “ชายขอบเมืองท่าริมทะเล” และสามารถมีแรงกดดันจากเส้นทาง คลังสินค้า และการมาถึงของคน/เรือได้

สิ่งที่ไม่ถูกอ้างจากแหล่งข้อมูลคือพิกัดของเซฟเฮาส์ เส้นทางลับ ตำแหน่ง NPC หรือขอบเขตที่แน่นอนของแคมเปญ สิ่งเหล่านั้นต้องเป็น `campaign-fiction` และแผนที่ต้องระบุเสมอว่าเป็นภาพอ่านแคมเปญ ไม่ใช่แผนที่สำรวจ

## การใช้กับภูมิภาคอื่น

แผนที่ UI ใช้ชื่อแคว้นที่ตัวสร้างแคมเปญรองรับเพื่อบอกตำแหน่งสัมพัทธ์และเลือกภาษาภูมิประเทศอย่างระมัดระวัง เช่น ชายฝั่ง เส้นทางน้ำ ที่ราบ หุบเขา หรือเชิงเขา ข้อความต้องไม่กล่าวว่าหมู่บ้าน ถนน ปราสาท หรือเหตุการณ์เฉพาะมีอยู่จริงหากไม่มี fact card ของปีและพื้นที่นั้นรองรับ
