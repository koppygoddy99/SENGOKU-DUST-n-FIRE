# Golden Examples ของคีย์หลัก

โฟลเดอร์นี้รับงานเขียนที่เจ้าของโปรเจกต์อนุมัติว่าเป็นเสียงที่ต้องการของ Dust & Fire โดยตัวอย่างจะใช้สอน **จังหวะ ภาษา รายละเอียดวัตถุ และความสัมพันธ์เชิงฐานะ** ไม่ใช่คัดลอกชื่อ เหตุการณ์ หรือบทสนทนาเข้าสู่ฉากใหม่

## วิธีส่งตัวอย่าง

ส่งไฟล์หรือวางข้อความเข้ามาได้ตามปกติ แล้วจะบันทึกเข้า `shared/narrativeGoldenExamples.ts` เป็นรายการที่มีข้อมูลดังนี้

| ฟิลด์ | ความหมาย |
|---|---|
| `id` | ชื่อสั้นเฉพาะของตัวอย่าง |
| `language` | `th` หรือ `en` |
| `tags` | เช่น `ronin`, `authority`, `merchant`, `document`, `water`, `pressure` |
| `text` | ย่อหน้าหรือฉากสั้นที่อนุมัติ |
| `source` | `user-approved` เท่านั้น |

ตัวอย่างจากเจ้าของมีลำดับเหนือกว่า foundation example เสมอ ระบบดึงมาได้ไม่เกินสองชิ้นต่อฉาก และใน prompt ระบุชัดว่าให้เลียนเฉพาะวิธีเขียน ห้ามนำเรื่อง ชื่อ หรือถ้อยคำไปใช้ซ้ำ

## เกณฑ์ก่อนรับเป็น Golden Example

ตัวอย่างต้องไม่มีภาษาเกม วัตถุหรือคำสมัยใหม่ ข้อมูลลับ และต้องบอกได้ว่าอยู่ในปี สถานที่ ฤดูกาล และความสัมพันธ์เชิงฐานะใด ถ้าสิ่งใดไม่ได้ระบุ จะใช้เป็นตัวอย่างภาษาได้ แต่ไม่ใช้เป็นข้อเท็จจริงประวัติศาสตร์ของฉากอื่น

## สถานะเริ่มต้น

ขณะนี้ library มีเฉพาะ foundation example ที่ย่อจาก contract ของโครงการ ยังไม่มีตัวอย่าง `user-approved` จนกว่าเจ้าของจะส่งให้
