# Style Profile จากนิยายที่ผู้ใช้อนุมัติ

เอกสารนี้สกัดจากบทที่ 1–5.1 ที่ผู้ใช้ส่ง ไม่ใช่ข้ออ้างว่าเป็นภาษาในประวัติศาสตร์คำต่อคำ เป้าหมายคือรักษา **คีย์งานของผู้ใช้** แล้วเพิ่มความแน่นของรายละเอียดตามขอบเขตหลักฐานของเกม

## เสียงหลักที่พบ

| แกน | ลักษณะใน corpus | กฎสำหรับ AI GM |
|---|---|---|
| ภาพทางกายภาพ | ฉากเริ่มด้วยกลิ่น ควัน ฝน ไม้ เกลือ คราบเลือด น้ำหนักอาวุธ และการเคลื่อนของร่างกาย | เริ่มจากรายละเอียด 1–2 อย่างที่ state รองรับ ไม่ใช้ฉากสำเร็จรูป |
| ความเจ็บและแรงงาน | แผล ความล้า และงานฝีมือส่งผลต่อทุกท่าทางโดยไม่ทำให้ตัวละครอ่อนแออย่างไร้เหตุ | ใช้เพียงเมื่อ state ส่งบาดแผล/ความล้ามา; แสดงผลในการจับ เดิน หายใจ หรือชั่งใจ |
| อำนาจ | ห้องโถง ท่าเรือ และค่ายเป็นพื้นที่ที่สิทธิ์ในการพูดไม่เท่ากัน | ให้ฐานะปรากฏจากระยะยืน พยาน คำสั่ง และผลของการโต้ตอบ ไม่ยัดคำยกยศ |
| ความลับ | ตัวละครอ่านประตู สายตา เสียง และท่าทีของคนรอบข้าง | อนุญาตเฉพาะสิ่งที่เห็น/ได้ยิน/อนุมานได้ ไม่เปิดเจตนาลับของ NPC |
| บทสนทนา | สั้น ตรง และมีแรงเสียดทาน; คำพูดเปลี่ยนเงื่อนไขหรือสมดุลอำนาจ | แต่ละบรรทัดต้องมีหน้าที่ ไม่ทำเป็นบทละคร และไม่จบด้วยคำถามรอผู้เล่น |
| ผลของเหตุการณ์ | ไม่มีความสำเร็จฟรี; ผลพาไปยังชื่อ หนี้ ความไว้วางใจ ข่าวลือ หรือภาระ | ย่อหน้าสุดท้ายต้องทิ้งร่องรอยจับต้องได้และทางเลือกถัดไป |

## การเพิ่มอรรถรสที่อนุญาต

เพิ่ม **สัมผัสทางกายภาพหนึ่งหรือสองชั้น** และ **ผลต่อความสัมพันธ์หนึ่งชั้น** ต่อฉากได้ แต่ห้ามขยายจนเปลี่ยน outcome จาก deterministic engine, เพิ่มประวัติศาสตร์เฉพาะจุดโดยไม่มี record, หรือย้ายความลับจาก dossier มาสู่ข้อความผู้เล่น

## รีเซิทบริบทภาษา

ภาษาไทยของเกมเป็นร้อยแก้วไทยร่วมสมัยที่เล่าโลกเซนโกคุ ไม่ใช่การแกล้งเขียนไทยโบราณหรือแปลญี่ปุ่นคำต่อคำ ภาษาอังกฤษจึงควรเป็น literary historical English ร่วมสมัยเช่นกัน ไม่ใช่ Elizabethan English ปลอม ความแท้ของญี่ปุ่นมาจากวัตถุ ฐานะ ขอบเขตความรู้ และเหตุการณ์ที่มีหลักฐาน ไม่ใช่การโรยคำญี่ปุ่นหรือคำยกยศ

ในระดับหลักฐาน ญี่ปุ่นคริสต์ศตวรรษที่ 16 มีงานจดหมายพู่กันจากกลุ่มชนหลากสถานะที่ต้องอ่านพร้อมรูปแบบ ผู้เขียน ผู้รับ และบริบท ไม่ใช่เพียงเนื้อความ [1] เคียวเง็นเป็นหลักฐานสำคัญของภาษาพูดช่วงมุโรมาจิถึงเอโดะ แต่ไม่ใช่ใบอนุญาตให้คัดสำนวนละครลงในชีวิตประจำวันทุกฉาก [2] ดังนั้นระบบยึด “บทสนทนามีน้ำหนักและผูกกับกิริยา” เป็นหลัก ไม่อ้างว่านี่คือคำพูดญี่ปุ่นจริงในปี ค.ศ. 1569
